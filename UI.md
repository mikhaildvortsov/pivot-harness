# Pivot: интерфейс харнеса, панели и клавиши

Файл справочный, в промпт pi не попадает. Расширения `ext/ui-*.ts`, общие примитивы в `ext/lib/ui-kit.ts` и `ext/lib/panel.ts`.

| Что | Как открыть | Где данные |
|---|---|---|
| Чаты (сессии): переключение, новый, переименование, все проекты | `alt+s`, `/sessions` | файлы сессий pi; стоимость не показывается |
| Подагенты: запуск → этап → агент, ✓/✗, скелетон-анимация, ход работы агента | `alt+w`, `/subagents` | события `subagent`, RPC pi-subagents, файлы сессий подагентов |
| Проверки: typecheck/lint, ревью (critic, Opus), сработавшие защиты | `alt+c`, `/checks` | события `check:result` от auto-verify, flow-skills, opus-director и tool_result защит |
| Палитра команд: панели, команды, skills, темы | `alt+k`, `/palette` | `pi.getCommands()`, темы pi |

Всегда на экране: шапка задачи (класс задачи, режим, ветка, PR), подвал (токены, кэш, стоимость задачи и сессии, остаток NanoGPT, огни здоровья RW/NG/GK/AN, модель маршрута), виджет подагентов над редактором, анимированные заголовки вызовов инструментов.

## Клавиши по платформам
Профили лежат в `ui-keys.json` (в репозитории): `darwin` (MacBook), `win32` (Windows), `linux`; `super` = Command. Свои значения без правки репозитория: `state/ui-keys.json` (не отслеживается git), например `{"sessions":"ctrl+r"}`; для действия можно указать список клавиш.

| Панель | macOS | Windows | Linux | Всегда |
|---|---|---|---|---|
| Чаты | `Ctrl+R`, `⌘⇧E` | `Ctrl+R` | `Alt+S` | `/sessions`, `/resume` |
| Новая вкладка с чатом (Ghostty) | `Ctrl+N` | `Ctrl+N` | `Alt+N` | `/tab` |
| Подагенты | `Ctrl+F`, `⌘⇧A` | `Ctrl+F` | `Alt+W` | `/subagents` |
| Проверки | `Ctrl+B`, `⌘⇧M` | `Ctrl+B` | `Alt+C` | `/checks` |
| Палитра команд | `Ctrl+Y`, `⌘⇧P`, `F1` | `Ctrl+Y`, `F1` | `Alt+K`, `F1` | `/palette` |
| Вставка картинки из буфера | `Ctrl+V`, `⌘V` | `Ctrl+V` | `Ctrl+V` | |

`keybindings.json` освобождает `Ctrl+B/F/Y/R` у pi (стрелки влево/вправо остаются; yank на `Ctrl+Shift+Y`, переименование в списке сессий на `Ctrl+Shift+R`) и добавляет `⌘V` к вставке картинки.

**Command в терминале.** pi получает `⌘`-сочетания только если терминал их передаёт, а не обрабатывает сам. Ghostty, kitty, WezTerm и iTerm2 (Profiles → Keys → «Report modifiers using CSI u» или kitty-протокол) передают. Если нет, привяжи в терминале `⌘V` к отправке `Ctrl+V`, тогда вставка картинки заработает и там. VS Code (`keybindings.json`):
```json
{ "key": "cmd+v", "command": "workbench.action.terminal.sendSequence", "args": { "text": "\u0016" }, "when": "terminalFocus" }
```
Windows: оболочечные части (`git`, `shasum`, `xargs` в проверках) требуют Git Bash или WSL.

## Автономность
Агенты не спрашивают разрешений: в pi нет окна подтверждения команд, правило записано в `AGENTS.md`, а подтверждения pi-subagents (очистка worktree, расширение лимита подагентов, открытие инспектора) выключены (`authorityPolicy` = `auto` в `extensions/subagent/config.json`). Остановить опасное могут только защиты (`git-guard`, `config-guard`, safety-net): блок для агента информация, а не вопрос. Единственный диалог, который остаётся: однократное доверие новому проекту при первом запуске (`defaultProjectTrust: "ask"` в настройках; `"always"` уберёт и его, но тогда pi будет исполнять расширения из любого клонированного репозитория).

## Старые команды, новая начинка
Старые команды pi остаются в меню `/` и работают, но открывают замену: `/resume` — панель чатов, `/new` — новый чат, `/name [текст]` — переименование — панель подагентов. Это перехват строки в редакторе (`ext/ui-legacy.ts`), потому что таблица встроенных команд pi зашита в код.

## Заставка, «vibing», размышления
- **Запуск.** Команда `pivot` (`bin/pivot`, для Windows `bin/pivot.cmd`) запускает pi с этой папкой как конфигом, поэтому репозиторий можно клонировать куда угодно. Установка в PATH на macOS/Linux: `sh bin/install` (ссылка в `~/.local/bin`); на Windows добавить `bin` в PATH.
- **Заставка (вступление на весь терминал).** `ext/ui-splash.ts`, сценарий в `ext/lib/boot.ts`: падающий дождь из цифр числа π, из частиц с шлейфами собирается силуэт π, он перетекает в объёмное тело и раскручивается; по буквам с вспышкой и тенью проявляется надпись PIVOT, пробегает блик, печатается подпись «автономная разработка · рой агентов · без угадываний». Дальше крутящийся π остаётся в цикле. Всё в полублоках `▀▄` с 24-битным цветом, 25 кадров/с, подстраивается под размер окна. Полное вступление играет один раз за запуск; она прячется, когда начинаешь печатать, и возвращается (сразу в цикле), если стереть текст в пустом чате. Как только в чате отправлена любая команда или запрос, она больше не показывается (в новом чате снова). Отключить: `PI_NO_SPLASH=1`.
- **«Vibing...».** Пока агент работает, строка прямо над вводом, у левого края: крутящийся спиннер, мерцающее слово «Vibing...», время и текущее действие. Встроенная строка загрузки pi скрыта (`ext/ui-style.ts`).
- **Размышления моделей** в ленту не выводятся (`hideThinkingBlock: true` в `settings.json`).

## Градиент
Цвета заставки, надписи «π pivot» в шапке и «Vibing...» берутся из выбранного градиента для тёмных тем (`ext/lib/gradients.ts`, цвета в hex, не зависят от темы). Полный проход переливания занимает 1 секунду (`GRADIENT_PERIOD` в `gradients.ts`). Сменить: `/gradient` (меню) или `/gradient ocean`; выбор хранится в `state/ui-gradient.json`. Варианты: `aurora` (по умолчанию), `ocean`, `ember`, `neon`, `mauve`.

## Ghostty: режим вкладок и пиксельный стиль
Запуск в Ghostty (`sh ghostty/install.sh`; `pivot-gui [папка]` открывает окно). Конфиг `ghostty/config`: тема Catppuccin Macchiato, шрифт JetBrains Mono, вкладки в заголовке окна, прозрачность и размытие, Option как Alt, шейдер `ghostty/pivot-void.glsl` (пиксельный фон: крупные туманности и квадратные звёзды за пустыми ячейками, свечение текста в цвет градиента, линии развёртки, свечение и шлейф курсора, виньетка; цвета из `/gradient`).

**Вкладка = чат.** Каждая вкладка и окно запускает pivot (`command` в конфиге), после выхода остаётся оболочка. `⌘T` новая вкладка-чат, `⌘1…9` переход, `⌘⇧[` и `⌘⇧]` листание. Запуск `pivot` из Dock-терминалов сам находит `pi` и `node` (добавляет типичные каталоги в PATH). Заголовок вкладки показывает состояние чата: `▖` спиннер пока работает, `✓` готово, `✗` ошибка, `○` пусто. Когда задача закончилась в фоновой вкладке, Ghostty помечает её колокольчиком (`bell-features`). Панель «Чаты» (`Ctrl+R`): у чатов, открытых в других вкладках, живой статус и метка «вкладка»; `Enter` переходит в нужную вкладку или открывает чат в новой, `Tab` открывает чат в текущей вкладке. Под капотом: каждая вкладка пишет файл состояния в `state/tabs/` (`ext/ui-tabs.ts`, `ext/lib/tabs.ts`), переключение через AppleScript Ghostty.

**Пиксельный стиль** по мотивам Pixel из pi-beautiful-tui (MIT): тяжёлые рамки `┏━┓┃┗━┛`, полоса `▐███···▌`, спиннер из четвертей блока `▖▌▘▀▝▐▗▄`, толстые линии `━`. π в заставке пиксельный и крутится как монета, надпись PIVOT блочным шрифтом.

## Подвал и набор текста
В подвале нет технических меток: ветка git показывается только настоящая (не `detached`), заполненность контекста модели выводится как «контекст N%» только когда она ≥ 60%, доля кэша не показывается. Набираемая буква сначала рисуется приглушённой на 45 мс и затем в полную яркость (`ext/ui-legacy.ts`). Фон шейдера не мерцает у поля ввода: туманность и звёзды плавно гаснут к нижней части экрана, шлейф и ореол курсора убраны.

## Фон под градиент
У каждого градиента свой фон терминала и своя «туманность» (`GRADIENTS` в `ext/lib/gradients.ts`): `aurora` #0e1621 (глубокий сине-бирюзовый), `ocean` #0a1424 (тёмный синий, спокойные звёзды), `ember` #1a1015 (тёплый винно-чёрный), `neon` #0b0f14 (холодный чёрный, больше звёзд), `mauve` #1e1e2e (база Catppuccin). `/gradient` переписывает цвет фона в `ghostty/config`, параметры в шейдере и просит Ghostty перечитать конфиг, так что всё подбирается автоматически.

## Ключи в терминалах из Dock
Ghostty и iTerm, запущенные не из оболочки, не читают `~/.zshrc`, и в них нет `NANOGPT_API_KEY` и `GONKA_API_KEY` (ошибка «router/auto routed to …, which has no credentials»). Лаунчер `bin/pivot` сам подтягивает ключи: из `local/env.sh` (не отслеживается git, строки `export NANOGPT_API_KEY=…`), а если файла нет, из строк `export` в `~/.zshrc`, `~/.zprofile`, `~/.bashrc`, `~/.profile`.

## Стартовый экран: выбор папки
Новая вкладка или окно Ghostty сначала открывает файловый менеджер yazi с иконками (`bin/pivot-start`, конфиг в `yazi/`): ходите по папкам (`↑↓`, `→`/Enter вперёд, `←`/`h`/Backspace назад), в нужной папке нажмите `q` или `p`, и pivot запустится именно там. `Q` или `Esc` выходят в терминал. Первые три раза показывается подсказка. Иконки берутся из Nerd Font (в конфиге Ghostty `JetBrainsMono Nerd Font`), тема yazi Catppuccin Macchiato, плагины `git` (отметки состояния) и `full-border`. С аргументом `pivot-start <папка>` выбор пропускается. Вкладки «чат из панели чатов» и `pivot-gui` открываются сразу в pivot, минуя выбор.

Проводник открывается в папке, где вы в прошлый раз запускали pivot (`state/last-dir`, пишется при каждом запуске), так что достаточно нажать `Enter` или `q`. Если запоминать нечего, берётся `local/start-dir` (не отслеживается git); переменная `PIVOT_START_DIR` перекрывает оба; без них — домашняя папка.

**Запуск:** `Enter`, `q` или `p` открывают pivot в текущей папке (файлы по `Enter` не открываются); войти в папку — `l`/`→`.

**Поиск в проводнике:** `f` ищет по названию файлы и папки по всей домашней папке (fzf: печатаете часть имени, `Enter` выбирает; папка открывается, у файла открывается его папка). `F` — только внутри текущей папки. `s` ищет через fd прямо в списке yazi, `/` фильтрует только текущую папку. Быстрые переходы: `g m` — medical_project, `g p` — «проекты и хакатоны», `g h` — домашняя.

**Флаг `--pick`.** `pivot --pick` (или `pivot --files`) в обычном терминале сначала открывает проводник, начиная с папки, откуда запущена команда; выбранная папка станет рабочей для pivot. Остальные флаги передаются дальше (`pivot --pick --continue`). Рамка поля ввода теперь переливается всегда: медленнее в простое, быстрее, пока агент работает.
